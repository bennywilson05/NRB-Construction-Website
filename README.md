# NRB-Construction-Website
This is a simple website that was created for the construction company NRB Construction. I am learning Node.js to send information to a secure database for their contact and estimate forms, as those forms required sensitive information that would be provided by any clients interested in working with the company. I am working towards using or creating an admin dashboard for easy access to any form submissions that haven't been sent via email to the owner of NRB Construction. This was my first ever website, and I'm very happy with how it turned out, as it took quite a bit to get the hang of coding anything in the frontend, and so far it's tedious learning the backend in comparison for me.
