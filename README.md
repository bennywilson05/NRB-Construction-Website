
# NRB Construction – Full-Stack Website

A full-stack web application developed for NRB Construction, a New Jersey-based construction company. The website provides customers with information about the company's services, showcases completed projects, and allows potential clients to submit estimate requests through an online contact form.

**Live Website:** https://nrbconstructionnj.com/

## Tech Stack

**Frontend**
- JavaScript
- HTML5
- CSS3

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

**Additional Technologies**
- Git & GitHub – Version control
- REST APIs – Frontend and backend communication
- Environment Variables – Secure configuration of sensitive credentials

## Features

### Responsive User Interface
- Responsive layout designed for desktop and mobile devices.
- Navigation between company information, services, and project sections.
- Custom styling and interactive UI components.

### Customer Estimate Requests
- Contact form allowing customers to submit project inquiries.
- Client-side form validation to ensure required information is provided.
- Backend API endpoints to process incoming form submissions.
- MongoDB integration for persistent storage of customer inquiries.

### Full-Stack Integration
- Communication between the React frontend and Express backend.
- Asynchronous HTTP requests for form submissions.
- Server-side processing and database operations using Mongoose.

## Project Architecture

The application follows a client-server architecture:

1. **Frontend:** Displays company information and collects customer inquiries.
2. **Backend:** Receives and processes requests through Express API endpoints.
3. **Database:** Stores submitted customer information using MongoDB Atlas and Mongoose.
